## Installation
To use this project, make sure you have [Dart SDK](https://dart.dev/get-dart) installed. Once Dart is set up, clone this repository and navigate to the directory:

```bash
git clone https://github.com/Yildirim-AliD/Dart.git
cd Dart
```

## Usage
You can run the individual Dart files like this:

```bash
dart run <file_name>.dart
```
